# 바다 친구 낚시 도우미

고등학교 1학년 학생도 읽고 수정할 수 있도록 HTML, CSS, JavaScript만 사용해 만든 간단한 낚시 규정 확인 웹앱입니다.

## 할 수 있는 일

- 물고기 사진 업로드와 미리보기
- 물고기 종류, 크기, 낚시 지역 입력
- 오늘 날짜를 기준으로 금어기 확인
- 최소 허용 크기 확인
- 쉬운 결과 표시: `잡아도 됩니다`, `잡으면 안 됩니다`, `크기가 너무 작습니다`
- 방생 사진 인증을 5회 쌓으면 예시 할인 쿠폰 발급

> 이 프로젝트의 규정은 **학습용 예시 데이터**입니다. 실제 낚시 규정이 아니므로, 낚시 전에는 반드시 공식 기관의 최신 정보를 확인하세요.

## 실행 방법

1. 이 프로젝트 폴더를 엽니다.
2. `index.html` 파일을 더블 클릭해 웹 브라우저에서 엽니다.
3. 사진을 고르고, 물고기 종류·크기·지역을 입력한 뒤 **잡아도 되는지 확인하기** 버튼을 누릅니다.

별도의 설치나 라이브러리가 필요하지 않습니다.

## 파일 구조

```
.
├── index.html     # 화면의 내용
├── style.css      # 색, 글자, 배치 같은 디자인
├── app.js         # 입력을 받고 결과를 계산하는 코드
├── fish-data.js   # 물고기 규정 예시 데이터
└── README.md      # 프로젝트 설명과 실행 방법
```

## 규정 데이터 수정하기

`fish-data.js` 파일을 열어 물고기 정보를 바꾸면 됩니다.

```js
{
  id: "rockfish",          // 코드에서 구분하는 이름
  name: "우럭",             // 화면에 보이는 이름
  minSize: 23,              // 최소 허용 크기(cm)
  closedSeason: { start: "04-01", end: "05-31" } // 금어기
}
```

금어기가 없는 물고기는 `closedSeason: null`로 적습니다.
